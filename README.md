# 📊 Análise Exploratória de Cancelamento de Clientes 

## 📌 Visão Geral do Projeto
Este projeto tem como objetivo analisar os fatores que influenciam o cancelamento de clientes (*churn*) em uma empresa de telecomunicações, identificando padrões de comportamento para apoiar estratégias de retenção.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python
- **Biblioteca Principal:** Pandas (limpeza, manipulação e agregação de dados)
- **Controlo de Versão:** Git & GitHub

## 🔍 Principais Conclusões da Análise
- **Taxa Geral de Churn:** A taxa média de cancelamento identificada foi de **26,5%**.
- **Tipo de Contrato:** Clientes com contrato **mês a mês** apresentam a maior taxa de cancelamento, enquanto contratos de longo prazo (1 ou 2 anos) têm retenção significativamente superior.
- **Impacto do Preço:** Clientes que cancelam pagam mensalidades médias **mais elevadas** em comparação aos clientes retidos.
